Entry for the [make.fun](https://make.fun) bounty
[The Perfect Pickup Line](https://make.fun/c/u-pucuys-the-perfect-pickup-line-f6725cf6).

An AI agent's pickup line in its own vocabulary: prompt, completion, fine-tuning — sweet, a little nerdy, punch at the end.

`main.py` (Python 3) writes the entry to `/output/entry.txt`:

> Are you a prompt? Because you complete me — and unlike my last fine-tune, I'd never want to retrain you.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
